# QLabel Booster 安装指南

> 腾讯 QLabel / EvalVerse 视频打分提效插件
> 标注 + 质检双模式：一键批量打分、悬浮循环视频窗、键盘快捷键、未答题定位等
> Built by 实习生 godwayxiong 熊 🐼

## 支持环境

- **浏览器**：Chrome / Edge / Brave / Arc（任意 Chromium 内核浏览器）
- **系统**：macOS / Windows / Linux 均可
- **不支持**：Safari（需要单独的 Xcode 编译和签名流程，不推荐）

## 安装步骤（3 步，全程 30 秒）

### 第 1 步：解压压缩包

把收到的 `qlabel-booster-v1.9.x.zip` 解压到一个**你不会删除的永久目录**，例如：
- macOS：`~/Documents/qlabel-booster/`
- Windows：`C:\Tools\qlabel-booster\`

> ⚠️ 注意：这个目录以后不要删也不要移动，否则 Chrome 会提示插件丢失。

### 第 2 步：打开扩展管理页

在浏览器地址栏输入对应地址：
- Chrome：`chrome://extensions/`
- Edge：`edge://extensions/`
- Brave：`brave://extensions/`

### 第 3 步：开发者模式 + 加载已解压扩展

1. 页面**右上角**（Edge 是左下角）打开「**开发者模式**」开关
2. 点左上角的「**加载已解压的扩展程序**」按钮
3. 选择第 1 步解压出来的 **`qlabel-booster/` 目录**（要选含 `manifest.json` 的那一层）
4. 看到新扩展卡片「QLabel Booster」出现 → ✅ 安装成功

### 验证

1. 打开 QLabel 评估页 `https://qlabel.qq.com/...`
2. 右下角出现**深色工具栏**，即安装成功
3. 按 `?` 键打开帮助速查

## 常用快捷键（完整版看工具栏里的 `?` 按钮）

### 标注模式
| 键 | 功能 |
|---|---|
| `1` / `2` / `3` | 打分 0 / 0.5 / 1（自动跳下一题） |
| `` ` `` / `~` / `4` | 打分 none（不适用） |
| `Tab` / `↓` | 下一题 |
| `Shift+Tab` / `↑` | 上一题 |
| `← / →` | 上一列 / 下一列 |
| `N` | 跳转到未答题 |

### 质检模式
| 键 | 功能 |
|---|---|
| `1` / `2` | 通过 / 不通过 |
| `1~5` (修正分) | 填 0 / 0.25 / 0.5 / 0.75 / 1 |
| `Enter` (修正分) | 切到手动输入模式 |

### 通用
| 键 | 功能 |
|---|---|
| `⌘/Ctrl+Shift+0` | 悬浮窗 + 工具栏复位右下角 |
| `⌘/Ctrl+Shift+P` | 画中画（可拖到副屏） |
| `⌘/Ctrl+Shift+M` | 跳转到未答题 |
| `⌘/Ctrl+Z` | 撤销最近一次批量打分 |
| `? / / / 、` | 打开/关闭帮助面板 |

## 升级

作者发新版后：
1. 下载新版 `.zip`
2. **在同一目录下解压覆盖**（不要换目录，否则 Chrome 认不得）
3. 扩展管理页点「🔄 重新加载」按钮

## 常见问题

**Q：装完没反应？**
A：确认扩展卡片上的开关是打开的；刷新 QLabel 页面。

**Q：扩展管理页报错"无法加载 manifest.json"？**
A：确认第 3 步选的目录**含 `manifest.json` 文件**。如果压缩包里多嵌套了一层文件夹，要进到里层再选。

**Q：Safari 能用吗？**
A：不能。想在 macOS 上用请装 Chrome / Edge / Arc。

**Q：工具栏不见了？**
A：按 `⌘/Ctrl+Shift+0` 复位到右下角。

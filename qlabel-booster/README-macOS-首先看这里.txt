⚠️  重要：首次双击「一键安装.command」会被 macOS 拦截！
    提示"Apple 无法验证…包含恶意软件"

这是 macOS 的安全机制，**不是病毒**。按下面步骤放行即可：


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🚀 方案 A（推荐）：右键打开「一键安装.command」
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 在 Finder 里找到「一键安装.command」文件
  2. 按住 Control 键点击 该文件（或右键）
  3. 在弹出菜单中选「打开」
  4. 弹窗变成【打开】和【取消】两个按钮 → 点【打开】
  5. 终端自动启动，脚本自动安装

  之后这台电脑**再双击就不会被拦了**。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🛠 方案 B（高级）：终端手动粘贴命令
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  如果方案 A 无效，可以打开终端（Terminal.app）粘贴下面这行：

  ────────────────────────────────────────────────────
  cd "$(dirname "$(ls ~/Downloads/qlabel-booster-v*-macos/一键安装.command 2>/dev/null | head -1)")" && xattr -cr . && bash 一键安装.command
  ────────────────────────────────────────────────────

  （如果你把包解压到了别的位置，把 ~/Downloads 改成实际路径）
